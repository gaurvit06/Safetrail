## Notes

- Counts are computed by plain code, so count accuracy must be 100%. Anything lower is a bug, not AI error.
- If R1 produced better text than R4, say so: this table measures cost, safety and accuracy, not prose quality.
- Cluster summaries follow the app's refresh limits in scenario time (one per minute, at most 3 per cluster); R1 re-summarises after every SOS. Copilot is counted as one brief per incident.
- Each run sends its own Prune run ids (so step and budget guards never carry over), so R4's cache hits depend on Prune's exact cache matching across run ids: see `cache_new_run` in docs/PRUNE_FIELDS.md.
- The injection scanner is plain English pattern matching; Hindi and Assamese tricks rely on Prune's detection.
